# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

## [0.1.4] - 2025-12-18
### Added
- Allow to use symfony/http-client version 8.0

## [0.1.3] - 2025-02-26
### Fixed
- RevoltCurlResponse::perform() signature

## [0.1.2] - 2025-02-25
### Fixed
- improved CPU utilization by using a longer delay between curl checks

## [0.1.1] - 2024-10-11
### Fixed
- Fixed a crash that occurred when a single response instance was read simultaneously in multiple fibers.

## [0.1.0] - 2024-08-21
- Initial release
